# NEXUS — Interactive Universe Explorer

A cinematic, responsive 3D solar-system experience built with React, TypeScript, Vite and Three.js.

## Features
- Animated 3D solar system with a starfield, planetary orbits, and Saturn's rings
- Select planets from the celestial-body rail or double-click a planet in the 3D scene
- Planet facts including orbital period, temperature, distance, and moon count
- Drag to rotate, scroll to zoom, pause/resume, zoom controls, and fullscreen
- Responsive layout with touch-friendly controls and mobile navigation

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```
